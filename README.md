# 四大审计对ESG评级质量的影响研究

## 研究概述

本仓库包含论文《外部监管对A股上市公司ESG评级质量的影响——以四大会计师事务所审计为例》的完整实证分析代码。

### 研究框架

本文从三个维度系统考察四大审计对ESG评级质量的影响：

| 维度 | 研究内容 | 被解释变量 | 核心模型 |
|------|---------|-----------|---------|
| 维度一 | ESG评级分歧度 | 机构间评级分歧 | 交错DID |
| 维度二 | ESG评级预测力 | t+1期负面新闻数 | 负二项回归 + DDD |
| 维度三 | ESG评级颗粒度 | 结果型指标数量 | 事件研究法（多期DID动态模型） |

### 核心发现

- 四大审计显著降低ESG评级分歧度（降低约0.055-0.057个单位）
- 四大审计显著提升ESG评级对未来负面新闻的预测力（水平效应）
- 四大审计对评级颗粒度的提升具有滞后性，审计后6-9年起效应显著
- 上述治理效应在内部治理薄弱（低机构持股）的企业中更突出

## 运行说明

### 环境要求

- Stata 16.0 或更高版本
- 需要安装的Stata包：
  - `ssc install winsor2`
  - `ssc install estout`
  - `ssc install coefplot`
  - `ssc install psmatch2`
  - `ssc install outreg2`

### 运行方式

```stata
# 方式一：交互式运行
do master.do

# 方式二：逐个运行
do code/dimension1_divergence.do
do code/dimension2_predictive.do
do code/dimension3_granularity.do
```

### 注意事项

1. **数据隐私**：本仓库仅提供模拟数据（`data_generation.do`），不包含任何真实企业数据。论文尚未发表，真实数据不对外提供。
2. **模拟数据说明**：模拟数据的样本结构（变量名、样本量、面板结构）与论文一致；数据生成参数（DGP）已按论文表2/表3/表4的系数方向与量级反向标定，因此模拟数据跑出的**结果方向、显著性水平与论文基本一致**。由于模拟数据固有的随机性，具体数值不会与论文完全相同，请勿将模拟输出直接当作真实复现结果引用。
3. **真实数据**：如需使用真实数据复现论文结果，请联系作者获取。

## 变量定义

### 维度一变量

| 变量 | 名称 | 定义 |
|------|------|------|
| esg | 基础评级分歧度 | 五大机构标准化ESG评级两两标准差均值 |
| esg_w | 加权评级分歧度 | 以机构认可度为权重的加权分歧度 |
| DID | 双重差分交互项 | Treat × Post |
| Treat | 处理组标识 | 曾被四大审计=1 |
| Post | 政策期标识 | 首次审计当年及之后=1 |
| SIZE | 企业规模 | 总市值（万元） |
| ISR | 机构持股比例 | 机构持股/总股数(%) |
| ROE | 净资产收益率 | 净利润/平均净资产(%) |
| ARR | 年化收益率 | 年化投资回报率(%) |
| TE | 股权集中度 | 股东权益合计 |
| LEV | 资产负债率 | 总负债/总资产(%) |

### 维度二变量

| 变量 | 名称 | 定义 |
|------|------|------|
| 负面新闻数_t1 | t+1期负面新闻 | 滞后一期ESG负面事件计数 |
| esg | 评级分歧度 | 同上 |
| Treat | 处理组标识 | 同上 |
| Post | 政策期标识 | 同上 |
| ESG_Treat | 交互项 | esg × Treat（核心关注） |
| ln_size | 企业规模（对数） | 总市值取对数 |
| ZCFZL | 资产负债率 | 总负债/总资产(%) |
| ROE | 净资产收益率 | 同上 |
| jgcg | 公司治理指数 | 机构治理评分 |

### 维度三变量

| 变量 | 名称 | 定义 |
|------|------|------|
| outcome_metrics | 结果型指标数 | ESG结果型指标绝对数量 |
| input_metrics | 投入型指标数 | ESG投入型指标绝对数量 |
| rel_year_k | 相对年份虚拟变量 | 以审计前1年为基准(k=-1) |
| size | 企业规模 | 总市值对数 |
